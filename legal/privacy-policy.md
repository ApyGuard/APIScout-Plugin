# ApyGuard APIScout Plugin Privacy Policy

**Effective date:** November 6, 2026

This Privacy Policy explains how Atlada Cyber Security, the owner of the ApyGuard brand ("ApyGuard," "we," "us," or "our"), handles information in connection with the ApyGuard APIScout Plugin (the "Plugin"). The Plugin is an integration for Codex and Claude Code that connects an ApyGuard account to local backend source code so that users can discover APIs, review findings, inspect endpoint evidence, export OpenAPI documents, and compare API specifications.

This Plugin-specific policy supplements the [ApyGuard Privacy Policy](https://app.apyguard.com/auth/sign_up/privacyPolicy). If there is a conflict, the ApyGuard Privacy Policy controls for ApyGuard account and platform processing, while this policy describes the Plugin-specific data flow.

## 2. Information We Process

Depending on how you use the Plugin, we may process:

- **Account and authentication data:** your name, email address, organization details, authentication state, and the installation identifier and access token used to connect the Plugin to your ApyGuard account.
- **Project and source metadata:** the local project path supplied to the Plugin, repository or project identifiers, framework information, file names, source locations, and API definitions discovered during a scan.
- **Scan inputs and outputs:** API routes, endpoint metadata, findings, source evidence, generated explanations, OpenAPI documents, comparison inputs, and export destinations requested by you.
- **Technical and diagnostic data:** client type, operating system information, timestamps, error details, and security logs needed to authenticate, operate, secure, and troubleshoot the Plugin.
- **Support information:** information you provide when contacting ApyGuard about the Plugin or an account.

The Plugin is designed to inspect local project files. You should not provide source code, API payloads, credentials, secrets, or personal data that you are not authorized to process.

## 3. How the Plugin Works

The Plugin runs its MCP server locally through Codex or Claude Code. Local source inspection, endpoint evidence collection, OpenAPI export, and local document comparison are performed on your device.

The Plugin does not upload your project files or source code to ApyGuard. It communicates with ApyGuard to authenticate your integration, to look up the asset linked to a project and the progress of its imports and scans using an identifier derived from the project's path, and, when you ask to create an asset or import documentation, to send the generated OpenAPI document and the asset details you provide. That document can contain API routes, schemas, descriptions taken from the code, findings, and source file paths. ApyGuard and its service providers may store this information as described in this policy.

The Plugin returns tool results, including API routes, findings, file paths, and source code excerpts, to the AI assistant you use it with. Your Codex or Claude Code client sends them to its model provider under that provider's own terms and privacy policy. The Plugin does not call an AI provider itself, and ApyGuard does not control that processing.

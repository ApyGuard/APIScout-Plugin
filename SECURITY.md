# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately in
one of these ways:

- Use **Report a vulnerability** on this repository's Security tab.
- Write to [support@apyguard.com](mailto:support@apyguard.com) with "Security" in
  the subject.

Include the plugin version, the affected tool or file, the steps to reproduce the
problem, and its impact. Do not include real access tokens, customer data, or
other people's source code.

## Supported versions

Security fixes go into the latest release only. Update to it before reporting if
you can.

## Scope

This policy covers the plugin in this repository, including its MCP server,
launcher, skills, release workflow, and bundled engine. Use the same contact for
problems in the ApyGuard services the plugin connects to.

Test only projects, systems, and accounts that you own or are authorized to assess.
